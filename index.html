So startest du

  1. Klick oben auf „Für Windows herunterladen“.
  2. Öffne Frostbyte.exe (am besten vorher auf den Desktop ziehen).
  3. Frostbyte öffnet sich von selbst – registriere dich mit Name und Passwort.
  4. Klick oben links aufs Logo → „Freund hinzufügen“ → dort steht dein fester Einladungs-Link. Den schickst du deinen Freunden.
  5. Deine Freunde öffnen den Link und registrieren sich – fertig! (Sie müssen nichts herunterladen.)
⚠️ Windows zeigt beim ersten Start vielleicht „Der Computer wurde durch Windows geschützt“. Klick dann auf „Weitere Informationen“ → „Trotzdem ausführen“. Das kommt, weil Frostbyte neu und noch nicht bekannt ist.
