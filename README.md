# ❄️ Frostbyte

Dein eigener Winter-Chat – wie Discord, aber selbst gemacht.
Chatten, Freunde adden, Server erstellen und telefonieren – ohne E-Mail, nur mit Name und Passwort.

## ⬇️ Herunterladen

👉 **[Frostbyte für Windows herunterladen](https://github.com/ossimaxi956-oss/frostbyte/releases/latest/download/Frostbyte.exe)**

Webseite: https://ossimaxi956-oss.github.io/frostbyte/

Frostbyte aktualisiert sich danach automatisch.

## Für Entwickler
- Geschrieben in Go, keine Abhängigkeiten.
- Neue Version veröffentlichen: `Version` in `main.go` erhöhen, `CHANGES.md` anpassen, Tag `vNN` pushen –
  GitHub baut dann automatisch die `Frostbyte.exe` und alle Apps updaten sich selbst.
